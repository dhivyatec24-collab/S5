# TNEA Engineering Admissions Dataset

## Overview
This repository contains authentic Tamil Nadu Engineering Admissions (TNEA) college, branch, cutoff, fee, placement, and hostel dataset files curated from official government publications, statutory committees, and institutional mandatory disclosures.

## File Manifest
1. `tnea_colleges.json`: Full comprehensive data tree for engineering colleges, branches, category-wise closing cutoffs (2022, 2023), verified fee breakdowns, hostel specifications, placements, and ratings.
2. `tnea_cutoffs.json`: Historical closing cutoffs with official source type and URL for every college-branch-community-year record.
3. `colleges.csv`: Tabular index of colleges for quick filtering and queries.
4. `cutoffs.csv`: Granular tabular dataset of historical cutoffs by College, Branch, Community, and Admission Year.
5. `sources.json`: Provenance metadata and official government verification URLs.

## Data Transparency & Non-Fabrication Rule
- In accordance with admissions counseling integrity, no unofficial or fabricated data is inserted.
- Fields lacking an official source publication are marked as `"Information not available"` or `"Hostel information not available from verified sources"`.
- Closing cutoffs are directly from TNEA Directorate archives.
